# Priscripto - Doctor Appointment Booking System

A full-stack MERN doctor appointment booking application where users can book appointments with doctors online.  
The project includes:

- User Panel
- Admin Panel
- Doctor Panel
- Online Appointment Management

---

# 🚀 Features

## 👨‍⚕️ User Features
- User Authentication
- Browse Doctors
- Book Appointments
- Cancel Appointments
- View Appointment History
- Online Payment Integration
- Responsive UI

## 🩺 Doctor Features
- Doctor Login
- Manage Appointments
- Mark Appointments Complete
- Update Availability
- Doctor Dashboard

## 🔐 Admin Features
- Admin Dashboard
- Add Doctors
- Manage Doctors
- Manage Appointments
- View Platform Statistics

---

# 🛠️ Tech Stack

## Frontend
- React.js
- Tailwind CSS
- Axios
- React Router

## Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- Cloudinary

# ⚙️ Environment Variables

Create `.env` file inside backend folder.

```env
PORT=4000

MONGODB_URI=your_mongodb_uri

JWT_SECRET=your_secret_key

CLOUDINARY_NAME=your_cloudinary_name
CLOUDINARY_API_KEY=your_cloudinary_api_key
CLOUDINARY_SECRET_KEY=your_cloudinary_secret_key


📦 Installation
Clone Repository
git clone https://github.com/sandeeptiwari21/DoctorManagement.git

Backend Setup
cd backend
npm install
npm run server


Frontend Setup
cd frontend
npm install
npm run dev

Admin Panel Setup
cd admin
npm install
npm run dev
